# 🛡️ Proyecto con Keycloak, PostgreSQL y API Node.js

Este repositorio contiene una arquitectura Dockerizada compuesta por:

- 🔐 [Keycloak](https://www.keycloak.org/) para autenticación y autorización.
- 🐘 [PostgreSQL](https://www.postgresql.org/) como base de datos.
- 🚀 API construida en [Node.js](https://nodejs.org/) utilizando [Prisma](https://www.prisma.io/) para la gestión de base de datos.

---

## 📦 Requisitos / Requirements

Antes de comenzar asegúrate de tener instalado:

- ✅ [Docker](https://www.docker.com/)
- ✅ [Docker Compose](https://docs.docker.com/compose/)

---

## ⚙️ Cómo levantar el entorno / How to start the environment

Desde la raíz del proyecto, ejecuta:

```bash
docker compose up --build
